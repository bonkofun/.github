# Bonko organization profile

This repository maintains the public Overview for the [Bonko GitHub organization](https://github.com/bonkofun).

GitHub renders `profile/README.md` on the organization's Overview when this repository is published as the public `bonkofun/.github` repository. The profile must be present on the repository's default branch.

## Editing

Make changes on `dev` and submit a pull request into `main`. Keep copy in English, link only to public resources, and verify commands and claims against their owning repositories. Do not duplicate detailed CLI documentation here.

The repository intentionally contains no organization-wide issue templates or default community policies; its scope is the public profile.
