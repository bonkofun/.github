# Repository instructions

- Maintain the public Bonko organization Overview in `profile/README.md`.
- Make changes on `dev`, commit with the repository-local Git identity, and submit a PR into `main` when remote publication is requested. Do not edit directly on main.
- Do not merge, publish, or rewrite history without explicit authorization.
- Keep documentation in English and verify public repository links and installation commands.
- Do not expose private repositories, internal operations, credentials or unverified product claims in the public profile.
- Keep organization-wide default community policies outside this task unless explicitly requested.
